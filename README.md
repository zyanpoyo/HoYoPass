# HoYoPass - ログボ＆交換コード自動受取ツール

HoYoverseゲーム（**原神**、**崩壊：スターレイル**、**ゼンレスゾーンゼロ**）の**デイリーログインボーナス**および**最新交換コード（シリアルコード）**をバックグラウンドで完全自動受け取りするGoogle Chrome拡張機能（Manifest V3）です。

毎日のHoYoLABログインボーナスの受け取り忘れや、煩わしい交換コードのコピー＆ペースト作業から完全に解放され、原石や星玉、ポリクロームなどの報酬を取りこぼすことなくゲーム内メールで受け取ることができます。

## 🌟 主な特徴

- **🎁 デイリーログインボーナス自動受け取り (毎日 01:05 JST)**:
  - HoYoLABの日付切り替え（毎日 00:00 UTC+8 / 日本時間 午前1:00）直後に独立したデイリーアラームが発火し、全3タイトルのログインボーナスを自動巡回して受け取ります。
  - ポップアップ上で「本日の受取状況（受取済 / 未受取）」と「今月の累計ログイン日数」をリアルタイムに確認でき、「今すぐボーナス受取」ボタンで手動受取も可能です。
- **🎟️ 交換コード定期自動引き換え (3時間毎)**:
  - 拡張機能の画面を開いていなくても、3時間周期で全3タイトルを自動巡回し、最新の有効コードを一括引き換えします。
  - 生放送直後などは「今すぐ引き換え実行」ボタンで選択中のゲームを即座に引き換え可能です。
- **💻 スリープ復帰・PC起動時の自動キャッチアップ**:
  - 夜間PCをシャットダウンやスリープにしていても、翌朝PCやChromeを起動したタイミングで「本日未受取のログインボーナス」と「未チェックの交換コード」を自動で直列キャッチアップ実行します。
- **🎛️ 機能別の独立ON/OFF制御 & カテゴリ別ログ**:
  - 「ログインボーナス自動受け取り」と「交換コード自動引き換え」の自動実行トグルを個別にON/OFF可能。
  - 直近50件の実行ログを「すべて / ログボ / コード」のタブでワン클リック絞り込み表示。
- **🛡️ ゼロトラスト・最高水準の安全性**:
  - パスワードや認証トークンの入力・保存、`cookies` 権限の要求は一切不要。
  - お使いのブラウザに保存された公式ログインCookie（`.hoyolab.com` および `.hoyoverse.com` のデュアルドメイン対応）をローカル透過通信（`credentials: 'include'`）でのみ利用し、外部サーバーへの個人情報送信・トラッキングは一切行いません。

## 📥 インストール方法 (Chromeへの導入)

### 1. Chrome ウェブストアから追加 (推奨・一般利用者向け)

> [!NOTE]
> 現在、Chrome ウェブストアへの公開準備中です。公開完了後はストアページより「Chromeに追加」をクリックするだけで簡単にご利用いただけます。

1. **Chrome ウェブストア**の HoYoPass ページを開きます（*公開準備中*）。
2. 「**Chromeに追加**」ボタンをクリックします。
3. 確認ダイアログで「**拡張機能を追加**」を選択します。
4. **ツールバーへの固定表示 (推奨)**:
   - Chrome右上ツールバーのパズルピースアイコン（拡張機能メニュー）をクリックし、「HoYoPass」のピン留めアイコンをクリックして固定します。

---

### 2. ソースコードから導入 (開発者・テスター向け)

<details>
<summary><strong>デベロッパーモードでの手動インストール手順を展開する</strong></summary>

Chrome ウェブストアを経由せず、ソースコードから直接ビルド・動作確認を行いたい場合は、以下の手順で導入できます。

1. **リポジトリをダウンロード**:
   - 本リポジトリの「Code」ボタン → 「Download ZIP」をクリックして解凍するか、Gitでクローンします：
     ```bash
     git clone https://github.com/zyanpoyo/HoYoPass.git
     ```
2. **Chrome拡張機能管理ページを開く**:
   - Chromeのアドレスバーに `chrome://extensions/` と入力してEnterキーを押します。
3. **デベロッパーモードを有効化**:
   - 画面右上にある「**デベロッパー モード**」のスイッチをONにします。
4. **拡張機能を読み込む**:
   - 画面左上に表示される「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
   - ダウンロード・解凍した `HoYoPass` フォルダ（またはビルド後の `dist/prod` / `dist/dev` フォルダ）を選択します。
5. **固定表示**:
   - ツールバーの拡張機能メニュー（パズルピースアイコン）からピン留めしてご利用ください。

</details>

## 📖 使い方ガイド

### Step 1: 初回起動と同意
- ツールバーのHoYoPassアイコンをクリックすると、初回のみ「利用開始のご確認」モーダルが表示されます。
- 免責事項およびプライバシーポリシーをご確認の上、「**同意して利用を開始する**」をクリックします（自動でログボ受取・コード引き換えの両方が有効になります）。

### Step 2: 公式サイトまたはHoYoLABでログイン
- ブラウザ上で、HoYoLABまたは各ゲームの公式交換サイトに普段通りログインしておきます（デュアルドメイン対応のため、どちらでログインしていても動作します）。
  - **原神**: [公式ログボページ](https://act.hoyolab.com/ys/event/signin-sea-v3/index.html?act_id=e202102251931481) / [公式コード交換サイト](https://genshin.hoyoverse.com/ja/gift)
  - **崩壊：スターレイル**: [公式ログボページ](https://act.hoyolab.com/bbs/event/signin/hkrpg/index.html?act_id=e202303301540311) / [公式コード交換サイト](https://hsr.hoyoverse.com/gift)
  - **ゼンレスゾーンゼロ**: [公式ログボページ](https://act.hoyolab.com/bbs/event/signin/zzz/index.html?act_id=e202406031448091) / [公式コード交換サイト](https://zenless.hoyoverse.com/redemption/gift)
- ログイン完了後、HoYoPassのポップアップを開くと、画面上部のステータスバッジが `Online: [あなたのキャラクター名]` に変化します。

### Step 3: ゲームの切り替え
- 上部のタブ（「原神」「スタレ」「ZZZ」）をクリックすることで、対象ゲームを瞬時に切り替えられます。
- 各ゲームごとにログイン状況、本日のログインボーナス受取状況・累計日数、交換コード操作が行えます。

### Step 4: 🎁 デイリーログインボーナスの自動・手動受取
- **自動受け取り**: 「**自動受け取り (毎日 01:05)**」のトグルスイッチがONになっていれば、毎日午前1:05（またはその日の初回PC起動・スリープ復帰時）に全3タイトルのログインボーナスを自動巡回して受け取ります。
- **手動受け取り**: 「**今すぐボーナス受取**」ボタンを押すと、現在選択中のゲームのログインボーナスを即座に受け取ります。
- **公式ページへ移動**: カード右上の「**公式 ↗**」ボタンを押すと、選択中ゲームの公式HoYoLABログインボーナスページが開きます。

### Step 5: 🎟️ 交換コードの自動・手動引き換え
- **定期自動引き換え**: 「**定期自動引き換え (3時間毎)**」のトグルスイッチがONになっていれば、3時間周期で全3タイトルの最新コードを自動検知・引き換えします。
- **手動引き換え**: 生放送直後などに「**今すぐ引き換え実行**」ボタンを押すと、現在選択中のゲームに対して即座に新規コードの引き換えを実行します。
- **公式交換サイトへ移動**: カード右上の「**公式 ↗**」ボタンまたはヘッダーのゲームアイコンをクリックすると、公式の交換コード入力ページが開きます。

## ❓ よくある質問 (FAQ)

<details>
<summary><strong>Q. ログインボーナスは何時に更新・自動受け取りされますか？</strong></summary>

HoYoLABのデイリーログインボーナスは毎日 **00:00 (UTC+8) ＝ 日本時間の午前1:00** に日付が切り替わります。
HoYoPassは毎日 **午前1:05** にデイリー専用アラームで自動受け取りを実行します。夜間にPCの電源を切っている場合でも、翌朝PCを起動してChromeを開いたタイミング（またはスリープ復帰時）に「本日未受取」であることを自動検知して即座に受け取ります。
</details>

<details>
<summary><strong>Q. PCをスリープさせたり、毎日シャットダウンしていてもバックグラウンド実行されますか？</strong></summary>

はい、確実に取りこぼさない仕組みを備えています。
- **スリープ運用の場合**: PCのスリープを解除して操作を再開したタイミング（`idle` 復帰）で、本日未受取のログインボーナスおよび前回から3時間以上経過したコード引き換えが直列で自動キャッチアップ実行されます。
- **毎日シャットダウン運用の場合**: Chromeを起動した際（`onStartup`）、15秒後に自動的にログインボーナスと交換コードのキャッチアップ判定が実行されます。
※なお、Chromeが完全に終了している状態やPCの電源が落ちている間は拡張機能は動作しません。
</details>

<details>
<summary><strong>Q. 「セキュリティ認証(CAPTCHA)が必要」と通知されました</strong></summary>

HoYoLAB側のセキュリティ保護（Geetestパズル認証）が一時的に発動した場合、自動リクエストだけでは突破できないため、通知またはダイアログでお知らせします。通知をクリックするか、ログインボーナスカード右上の「公式 ↗」ボタンから公式ページを開いて1度手動でチェックインしてください。
</details>

<details>
<summary><strong>Q. 手動でボタンを押した際、他のゲームも同時に処理されますか？</strong></summary>

いいえ、ポップアップ画面の「今すぐボーナス受取」および「今すぐ引き換え実行」ボタンは、**現在選択しているタブのゲームに対してのみ**即時実行を行います。なお、バックグラウンドでの自動実行（毎日 01:05 のログボ受取 / 3時間毎のコード引き換え）は、3タイトル全てを自動で巡回します（未プレイのタイトルは安全にスキップされます）。
</details>

<details>
<summary><strong>Q. 垢BAN（アカウント停止）のリスクはありますか？</strong></summary>

本拡張機能は、公式Webサイトで人間が操作するのと同一の公式APIを使用し、かつ適切なリクエスト間隔とバックオフ制御を設けて公式サーバーに過度な負荷をかけないよう厳格に設計されています。また、パスワードや機密トークンの保存・不正通信も行いません。ただし、非公式ツールである点をご留意の上ご利用ください。
</details>

### プロダクトフレーバー (dev / prod) のビルド & 開発
同一コードベースから、開発・検証用（短縮周期・DEV表示）と製品用（本番周期）をコマンド1つで独立ビルドできます：

```bash
# 開発用フレーバーのビルド（コード定期実行: 3分毎、名称: HoYoPass [DEV]）
npm run build:dev

# ソースコード変更の自動監視・再ビルド（開発時推奨）
npm run watch:dev

# 製品用フレーバーのビルド（コード定期実行: 3時間毎、本番名称）
npm run build:prod
```

### 開発・テスト手順
```bash
# 依存関係セットアップ（アイコン生成等）
npm run setup

# 単体テストの実行（Node.js組み込みテスト）
npm test

# 機密情報混入スキャン
npm run check-secrets

# ストア掲載用スクリーンショットの自動生成
npm run generate-screenshots
```

### ストア公開用パッケージ (ZIP) の作成
Chrome Web Store 申請用の配布パッケージは以下のコマンドで一括生成できます：

```bash
npm run package
```

- **出力先**: `dist/hoyopass-v1.1.0.zip`
